# World / Environment Production Skills

**Status:** Bootstrap workspace

`world-environment-production-skills` is a Production Skills project for reusable world and environment production intelligence across real-world reconstruction, fictional worlds, modular/procedural environments and simulation-driven representation.

This repository is currently a minimal bootstrap workspace. Detailed bootstrap research and staged design outputs belong under `docs/research-logs/`.

The production repository scaffold, skills, examples, Extension Packs, benchmarks, tooling and CI will be created only after the bootstrap process has designed and specified them.
